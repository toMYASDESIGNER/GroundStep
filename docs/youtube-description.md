# GroundStep — YouTube metadata

## Title

GroundStep — Proof-Gated Physical Guidance for Codex | OpenAI Build Week

## Description

GroundStep never gives you the next step until reality proves the last one happened.

Built with Codex and GPT-5.6 for OpenAI Build Week, GroundStep guides physical tasks one bounded action at a time. The user submits a fresh photo, Codex inspects visible evidence, and a deterministic state machine decides whether the next instruction can be unlocked. Mismatch, uncertainty, and unsafe evidence all fail closed.

Live demo: https://tomyasdesigner.github.io/GroundStep/
Source code: https://github.com/toMYASDESIGNER/GroundStep

The demonstration uses a sanitized replay of seven real smartphone photographs. Original photos and camera metadata remain local and are excluded from Git.
